# Security policy

## Supported versions

Security fixes are released for the latest published version of Psych. Upgrade to the newest release before reporting a problem that may already be fixed.

## Report a vulnerability

Please report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/psych-systems/psych-runtime/security/advisories/new). Do not open a public issue or include credentials, tokens, customer data, or other secrets in a report.

Include the affected version, impact, reproduction steps, and any suggested mitigation you have. We will acknowledge the report, investigate it, and coordinate disclosure and a fix with you.
