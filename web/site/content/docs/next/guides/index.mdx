Each guide is one feature: what it is for, the code that uses it, and the
mistakes that are easy to make. They are the same files that ship as skills
for coding agents (`psych skills install`), so there is one copy and it is the
tested one.

If you have not run an agent yet, start with [Get started](/docs/next/get-started).

- [Connect MCP servers](/docs/next/guides/mcp), and [authenticate to one with OAuth 2.1](/docs/next/guides/mcp-oauth).
- [Work with other agents over A2A](/docs/next/guides/a2a), in both directions.
- [Run code the model writes](/docs/next/guides/sandbox), in a subprocess or a container.

- [Delegate to subagents](/docs/next/guides/subagents).
